---
title: Ayuda para chroot de CachyOS
description: Herramienta de ayuda para facilitar el chroot en sistemas
---

[cachy-chroot](https://github.com/CachyOS/cachy-chroot) es un sencillo programa de soporte que facilita el proceso de chroot en una instalación existente de CachyOS o basada en Arch. Enumera todas las particiones detectadas en la máquina y también permite listar subvolúmenes BTRFS.
Por último, `cachy-chroot` también admite sistemas cifrados mediante LUKS. Asignará cada entrada `fstab` a su entrada `crypttab` designada y cerrará correctamente todos los volúmenes LUKS al salir del chroot.

## Uso

El proceso de chroot **debe** realizarse en una ISO live. A continuación, se muestra un ejemplo del uso de `cachy-chroot` en una instalación BTRFS de CachyOS.

```sh title="haciendo chroot con cachy-chroot"
sudo su # Introducir el usuario root en la ISO en vivo
pacman -Sy cachy-chroot # Asegurarse de que cachy-chroot esté actualizado a la última versión
cachy-chroot

Info: Found partition: Partition: /dev/nvme0n1p4: FS: btrfs UUID: 66e84339-8c77-4131-afce-50ec2cf67a80

Info: Selected BTRFS partition, mounting and listing subvolumes...

```

Tras seleccionar la partición raíz, el programa solicitará montar particiones adicionales, por ejemplo, la partición `/boot`

```sh title="Montando particiones adicionales"
✔ Do you want to mount additional partitions? · yes
? Enter the mount point for additional partition (e.g. /boot) type 'skip' to cancel:  › # /boot on systemd-boot, /boot/efi on GRUB and rEFInd
```

Al finalizar, salga del entorno chroot indicando `exit` en el símbolo del sistema o presionando `CTRL+D` en el teclado.

```sh title="Saliendo del entorno chroot"
exit
```
